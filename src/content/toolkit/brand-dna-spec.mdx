This spec is the fillable version of [Design](/workflows/design)'s five Brand DNA components. Five fields, plus two mechanics that make the whole thing enforceable rather than aspirational. Every field has to pass one test. Can an agent act on it without a human translating first?

<Section index="01" kicker="A spec, not a mood board" title="What it's for">

Design already defines the five components: tone-of-voice rules, visual grammar, proof cues, claims boundaries, and required disclaimers. This template doesn't re-explain them. It gives each one a field an agent can check its own output against before generation, the same standard the [Machine-Readability Test](/workflows/design) applies line by line.

</Section>

<Section index="02" kicker="Before the pipeline connects" title="When to use it">

Fill this out before connecting a brand to any AI content-generation workflow. Also fill it out the moment an existing brand guide turns out to be adjectives a person must interpret, not rules a system can enforce. "Fresh and vibrant" is a guideline. "Saturation 70–85%, no stock" is a spec.

</Section>

Two mechanics make the spec enforceable rather than descriptive:

The violation-words list behind that second draft — "elevate," "unlock," "obsess," "artisanal" — is append-only: an entry gets added the first time it shows up in a rejected draft and never removed, the same discipline the [AI Hallucination Guardrails](/toolkit/ai-hallucination-guardrails) checklist applies to fabricated claims.

<Section index="06" kicker="What machine-readable costs, and buys" title="Design decision">

<Callout kind="key" title="An enforceable spec is a narrower spec">
Structured fields cost real nuance. "Feels fresh and vibrant" captures something a hex code and an f-stop range never will. The trade is deliberate: a spec that keeps the adjective is unusable at generation time, so nothing in it actually governs the ten thousandth asset the way it governed the first. A narrower spec that an agent can check itself against beats a richer one that only a person can interpret, because only one of them scales past a human review queue.
</Callout>
