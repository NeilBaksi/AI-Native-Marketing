## What actually happens when you visit

The site is a set of static files hosted on GitHub Pages and served straight to your browser — there's no application server in between, and <Mark>nothing about your visit is logged anywhere the author controls.</Mark> GitHub's own hosting infrastructure sees standard web server logs (the same as any GitHub Pages site), governed by [GitHub's own privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement), not anything this project adds on top.

Search is a client-side lookup over the page manifest that runs entirely in your browser — <Mark>typing a query never sends it anywhere.</Mark>
